# SVG CLI Editor

高级软件课程作业。

Lab1 已完成 Phase 1–5。当前可通过 `npm run cli` 使用 `init`、`create`、`delete`、`move`、`scale`、`set`、`group`、`ungroup`、`addto`、`front`、`back`、`undo`、`redo` 和 `help` 编辑 SVG 文档；文档快照、撤销重做和 IO 屏障已实现。SVG IO 与显示类命令按课程要求留到后续阶段。

```text
npm install
npm run build
npm test
npm run cli
```
